Visão Macro do Desafio BNPL (Aplazo Challenge)

O desafio consiste no desenvolvimento de um sistema de crédito sob demanda no modelo Buy Now, Pay Later (BNPL), cobrindo o ciclo de vida completo de originação e acompanhamento de empréstimos para compras parceladas:

POST
Elegibilidade & Cadastro Automático
/v1/customers

Avaliação de idade em tempo de requisição: aceita apenas clientes entre 18 e 65 anos. Atribuição instantânea de limite de crédito baseado na faixa etária:

Faixa Etária Limite Concedido
18 a 25 anos$3.000,00
26 a 30 anos$5.000,00
31 a 65 anos$8.000,00
Emissão de token JWT assinado (X-Auth-Token) para utilização imediata.
POST
Concessão de Empréstimo BNPL
/v1/loans

Validação estrita contra o saldo de crédito remanescente do cliente e dedução atômica transacional. Seleção dinâmica de esquema de amortização:

  • Scheme 1: 13% de juros para clientes com primeiro nome iniciado em C, L ou H.
  • Scheme 2: 16% de juros para cliente com ID > 25 ou fallback.
Divisão em 5 parcelas quinzenais (D+14 a D+70) com conciliação exata de centavos na última parcela.
GET
Consultas Seguras
/v1/customers/{id} & /v1/loans/{id}

Endpoints autenticados via Bearer JWT com detalhamento de limites, saldo remanescente, metadados de criação e cronogramas completos de amortização e status de cada parcela (NEXT / PENDING).

RFC 7807
Tratamento Padronizado de Erros
Códigos APZ000001 a APZ000008

Respostas JSON estruturadas sob o contrato OpenAPI com códigos rastreáveis para cliente menor de idade, token ausente/inválido, cliente não encontrado, crédito insuficiente, requisições malformadas e erros internos.

Como Rodar Localmente com Maven

Passo 1: Iniciar PostgreSQL 16

Inicie uma instância local do PostgreSQL 16 (ou utilize o serviço provido pelo Docker Compose):

docker run --name bnpl-postgres \
  -e POSTGRES_DB=bnpldb \
  -e POSTGRES_USER=bnpluser \
  -e POSTGRES_PASSWORD=bnplpass \
  -p 5432:5432 -d postgres:16-alpine
Passo 2: Iniciar a Aplicação Spring Boot
rtk ./mvnw spring-boot:run

Por padrão, a aplicação conecta em jdbc:postgresql://localhost:5432/bnpldb com usuário bnpluser e senha bnplpass. Você pode sobrescrever configurações via variáveis de ambiente:

DB_URL="jdbc:postgresql://localhost:5432/bnpldb" \
DB_USERNAME="bnpluser" \
DB_PASSWORD="bnplpass" \
rtk ./mvnw spring-boot:run

Como Rodar com Docker Compose

Para construir a imagem e subir tanto o banco PostgreSQL 16 quanto o serviço da API BNPL em um único comando:

docker compose up --build

Para rodar em segundo plano (modo detached):

docker compose up -d --build

Para parar e remover os contêineres e volumes:

docker compose down -v
Serviços Expostos:
  • BNPL REST API: http://localhost:8080
  • PostgreSQL Database: localhost:5432 (DB: bnpl, User: postgres, Pass: postgres)

Testes Automatizados com Newman / Postman

O repositório inclui uma suíte automatizada de testes de API e contrato baseada em Postman Collection v2.1 e executável via Newman (CLI do Postman).

  1. POST /v1/customers: Cadastro de cliente elegível (idade 35 anos) e captura dinâmica do ID e do token JWT (X-Auth-Token).
  2. GET /v1/customers/{id}: Consulta do perfil e limite de crédito concedido ($8.000,00).
  3. POST /v1/loans: Criação de empréstimo de $1.000,00 com aplicação do esquema de juros Scheme 1 (13%) e 5 parcelas quinzenais.
  4. GET /v1/loans/{id}: Consulta e validação do cronograma de amortização (soma total de $1.130,00 com conciliação exata de centavos).
  5. GET /v1/customers/{id}: Validação do saldo de crédito remanescente atualizado ($7.000,00).

  • Cadastro de cliente menor de idade (< 18 anos) retornando 400 Bad Request com código APZ000002.
  • Requisição sem cabeçalho de autenticação retornando 401 Unauthorized com código APZ000007.
  • Consulta de cliente inexistente retornando 404 Not Found com código APZ000005.
  • Solicitação de empréstimo excedendo o limite de crédito disponível retornando 400 Bad Request com código APZ000006.
Comandos de Execução da Suíte Newman:

1. Instalar dependências (Node.js):

rtk npm install

2. Executar a suíte via NPM:

rtk npm run test:api

3. Execução direta via npx newman (sem instalar localmente):

rtk npx newman run postman/bnpl-api.postman_collection.json \
  -e postman/local.postman_environment.json \
  --reporters cli

4. Gerar Dashboard HTML Interativo (htmlextra):

rtk npm run test:api:html

Para abrir o relatório no navegador: xdg-open target/newman/report.html
