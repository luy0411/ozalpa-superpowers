Consulta de Cliente

GET /v1/customers/{customerId} Consulta cadastral e saldo remanescente em tempo real

Recupera informações cadastrais, a linha de crédito global e o saldo disponível para contratação de novas compras parceladas.

1. Visão de Produto e Negócio

Objetivo

Permitir a consulta do status cadastral e financeiro de um cliente cadastrado, fornecendo a visibilidade de sua linha de crédito total e, principalmente, do saldo disponível em tempo real para novas compras no modelo Buy Now, Pay Later (BNPL).

Proposta de Valor

  • Transparência de Limite: Permite que o cliente ou o checkout de e-commerce verifique instantaneamente o poder de compra remanescente antes de submeter uma nova transação.
  • Segurança e Isolamento: Protegido por autenticação JWT (Bearer ou X-Auth-Token), garantindo que dados cadastrais e limites só sejam acessados por clientes autenticados.

Regras de Negócio e Validações

Identificador UUID

A busca é realizada exclusivamente pelo UUID público do cliente (customerId), sem expor a chave primária sequencial interna do banco.

Autenticação Obrigatória

Requisições sem token válido ou com assinatura expirada retornam 401 Unauthorized com código APZ000007.

Cliente Inexistente

Caso o customerId não exista na base de dados, a API retorna 404 Not Found com código de erro APZ000005.

Formato Inválido

Identificadores que não representam um padrão UUID válido são interceptados com 400 Bad Request (APZ000004).

2. Diagrama de Sequência Interno

Fluxo detalhado de execução interna entre o filtro de autenticação JWT, Spring MVC Controller, serviço de consulta, repositório JPA e mapper:

Sequência: JwtAuthenticationFilter → CustomerController → CustomerRepository Mermaid.js 
sequenceDiagram
    autonumber
    actor Client as Cliente / App Mobile
    participant Filter as JwtAuthenticationFilter
    participant Controller as CustomerController
    participant Service as CustomerService
    participant Repo as CustomerRepository
    participant DB as PostgreSQL
    participant Mapper as CustomerMapper

    Client->>Filter: GET /v1/customers/{customerId} (Header Authorization: Bearer JWT)
    activate Filter

    Filter->>Filter: Valida token e extrai claims
    alt Token Ausente ou Inválido
        Filter-->>Client: 401 Unauthorized (APZ000007 / UNAUTHORIZED)
    else Token Válido
        Filter->>Filter: Autentica SecurityContext
        Filter->>Controller: Encaminha requisição
    end
    deactivate Filter

    activate Controller
    Controller->>Service: getCustomerByExternalId(customerId)
    activate Service

    Service->>Repo: findByExternalId(customerId)
    activate Repo
    Repo->>DB: SELECT * FROM customers WHERE external_id = ?
    DB-->>Repo: Registro encontrado / vazio
    Repo-->>Service: Optional CustomerEntity
    deactivate Repo

    alt Cliente não encontrado
        Service-->>Controller: throw CustomerNotFoundException
        Controller-->>Client: 404 Not Found (APZ000005 / CUSTOMER_NOT_FOUND)
    else Cliente Encontrado
        Service->>Mapper: toCustomerResponse(entity)
        activate Mapper
        Mapper-->>Service: CustomerResponse
        deactivate Mapper
        Service-->>Controller: CustomerResponse
    end
    deactivate Service

    Controller-->>Client: 200 OK (Body: CustomerResponse)
    deactivate Controller

3. Contrato da Requisição e Resposta

Parâmetros de Path e Cabeçalhos

Parâmetro / Header Tipo Obrigatoriedade Descrição e Formato
customerId Path (UUID v4) Obrigatório Identificador público único do cliente (ex: 3fa85f64-5717-4562-b3fc-2c963f66afa7).
Authorization Header HTTP Obrigatório Token JWT no formato Bearer <token> (ou header alternativo X-Auth-Token).
